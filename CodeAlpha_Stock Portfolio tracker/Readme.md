📈 Task 2: Stock Portfolio Tracker

A simple Python program that calculates the total investment value of a stock based on the current market price and user-defined quantity. It also saves the final receipt/result into a text file.

## 🚀 Features
* Supported stocks: AAPL ($180), TSLA ($250), GOOGL ($140), MSFT ($330).
* Takes real-time user input for stock name and quantity.
* Automatically calculates the total investment value.
* File Handling: Saves the final value inside a `portfolio.txt` file.

## 🛠️ Technologies Used
* Python 3.x
* File I/O Operations (`open()`, `write()`)

## 💻 How to Run
1. Run the script.
2. Enter the stock name (e.g., TSLA) and the quantity you want to buy.
3. Check the folder for `portfolio.txt` to see the saved output.
